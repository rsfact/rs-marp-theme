# Custom Marp Theme

## How to Use

1. Set `theme/example.md` to your LLM's system prompt.
    - https://rsfact.github.io/rs-marp-theme/theme/example.md
2. Make your slides in markdown with LLMs.
3. Paste the markdown and `theme/style.css` to https://marpwebeditor.app/
    - https://rsfact.github.io/rs-marp-theme/theme/style.css
