# RS Simple Marp Theme

1. Set [./theme/example.md](https://raw.githubusercontent.com/rsfact/rs-marp-theme/refs/heads/main/theme/example.md) to your LLM's system prompt.

2. Make your slides in markdown with LLMs.

3. Paste the markdown and [./theme/style.css](https://raw.githubusercontent.com/rsfact/rs-marp-theme/refs/heads/main/theme/style.css) to [MarpWebEditor](https://marpwebeditor.app/)
